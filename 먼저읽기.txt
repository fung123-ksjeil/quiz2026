6단원 온라인 시험지 - 전체 기능 테스트

1. ZIP을 내려받아 '모두 압축 풀기'로 압축을 해제하세요.
2. Python 3.10 이상이 설치된 컴퓨터에서 실행하세요.
   Windows: Windows_테스트실행.bat 더블클릭
   macOS/Linux: 이 폴더에서 python3 테스트실행.py 실행
3. 실행하면 관리자 페이지가 열립니다. 비밀번호는 대화에서 요청하신 값으로 설정되어 있습니다.
4. 요청하신 관리자 비밀번호로 로그인하세요.
5. 반 이름 입력 → 반 만들기 → 시험 공개 → 응시 코드 확인.
6. 실행 창에 표시된 '학생 시험 입장' 주소를 다른 브라우저/시크릿 창으로 열어
   코드, 테스트 학번과 이름을 입력하세요.
7. 학생이 답을 입력하는 중 관리자에서 시험 잠그기를 눌러 보세요.
   약 3초 이내 시험 화면이 잠깁니다. 다시 공개하면 이어서 응시할 수 있습니다.
8. 모든 문항과 16번 두 칸에 답한 뒤 최종 제출하세요.
   관리자에서 학생별 총점과 문항별 정오를 확인할 수 있습니다.
   답안 상세에서 서술형 점수(0~5점)를 수정하고 점수 저장을 누르세요.
   서술형 자동 제안은 참고용입니다. 교사가 문맥을 확인해 주세요.
9. 연습문제 모드는 준비 화면만 있습니다. 문제는 추후 추가 예정입니다.

실행 창을 닫으면 서버가 종료됩니다. 데이터는 .data 폴더에 저장됩니다.
서버를 다시 켜면 주소의 포트 번호가 바뀔 수 있으니 실행 창의 새 주소를 사용하세요.
학생 기록을 같은 컴퓨터에서 유지하려면 서버를 종료하지 않고 테스트하세요.
다른 기기에서 접속하는 인터넷 배포가 아니라, 내 컴퓨터에서 실제 기능을 확인하는 패키지입니다.
저장소 전체를 정적 호스팅에 업로드하지 마세요.
화면 캡처와 다른 기기의 검색은 일반 웹에서 완전히 차단할 수 없습니다.

관리자 화면의 학생별/반별 삭제 버튼으로 기록을 삭제할 수 있습니다. 자동 삭제하지 않습니다.
GitHub 저장은 별도 비공개 저장소와 Render 환경 변수 설정이 필요하며 README.md에 설명되어 있습니다.
