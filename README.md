# 6단원 온라인 시험

HWP의 객관식 15문항, 서술형 1문항. Python 3.12 표준 라이브러리와 SQLite로 실행합니다. 정적 파일 서버로 실행하지 마세요. 기존 단일 HTML 시험지는 폐기했습니다.

## 실행

안전한 방법으로 서버 프로세스에 `ADMIN_PASSWORD`(6자 이상)를 설정한 후 이 폴더에서 `python3 server.py`를 실행합니다. 비밀번호를 소스나 명령 기록에 적지 마세요. `/admin`에서 관리자 로그인, `/`에서 학생 입장, `/practice`에서 연습문제 준비 화면을 제공합니다. 기본 주소는 127.0.0.1:8000입니다. 실제 배포는 아직 하지 않았습니다.

환경 설정: `HOST`(기본 127.0.0.1), `PORT`(8000), `QUIZ_DATA_DIR`(기본 .data), `COOKIE_SECURE`(HTTPS 배포 시 반드시 1). 인터넷 공개 시 HTTPS 역방향 프록시를 사용하고 데이터 폴더와 비밀번호를 영구 저장소/비밀 설정으로 관리하세요. 저장소 전체를 정적 호스팅에 올리지 마세요. 서버는 정해진 공개 파일만 제공하고 questions.json, 데이터베이스와 원본 파일은 제공하지 않습니다. 실행 중인 프로세스는 게시나 다음 작업에서 자동 복구되지 않습니다.

## 운영

1. 관리자가 반을 만들면 기본 잠김 상태로 고유 응시 코드가 발급됩니다.
2. 시험 링크·코드 복사 버튼으로 반에 안내할 내용을 복사합니다. 실제 메시지 전송은 하지 않습니다.
3. 해당 반의 시험을 공개하면 학생이 코드, 학번, 이름으로 입장할 수 있습니다.
4. 작성 답안은 서버에 자동 저장되며 같은 브라우저의 쿠키로 이어서 응시합니다. 쿠키가 사라지면 기존 답안과 연결할 수 없습니다. 학번·이름은 자기 기입 방식이며 학생 본인 인증은 아닙니다. 공유 코드가 다른 반에 유출되는 것까지 방지하지 못합니다.
5. 관리자가 반을 잠그면 입장·문항 조회·저장·제출을 즉시 서버에서 거부합니다. 기존 학생 화면은 3초 간격의 확인 후 가려집니다. 잠금/연결 끊김 중 미저장 답안은 창을 유지하면 메모리에 보존되며 재공개 시 다시 저장합니다. 잠긴 중 새로고침하면 미저장 답안은 사라집니다. 모든 학생 제출 후 잠그세요.
6. 최종 제출 후 학생에게 문항/답안을 다시 보내지 않으며 수정 불가입니다. 관리자는 응시 상태, 답안, 화면 이탈 및 제한 동작 기록을 확인합니다. 객관식은 제공된 정답으로 자동 채점합니다. 서술형은 정부·시민의 두 입력란을 핵심 표현으로 검토해 0~5점 참고 점수를 제안하며 교사가 수정·저장할 수 있습니다. 총점은 20점입니다.
7. 연습문제 모드는 별도 메뉴와 준비 화면만 구현했습니다. 시험 문항을 재사용하거나 공개하지 않습니다. 추후 문제 제공 시 추가합니다.

## 시험 화면 제한의 범위

문항 선택·복사·잘라내기·붙여넣기·우클릭·드래그·일반 저장/인쇄 단축키를 제한하고 인쇄물은 비웁니다. 화면 전환/포커스 이탈 시 문제를 가리고 서버에 기록하며, 학생이 돌아가기 버튼을 누르면 재확인합니다. 전체 화면은 선택적으로 요청합니다. 학생 식별 정보와 이탈 기록이 저장됨을 입장 화면에서 알립니다. 관리자 화면에서 개인정보를 확인하므로 공용 기기에서는 로그아웃하세요.

일반 웹에서는 OS 화면 캡처·화면 녹화·카메라 촬영·다른 기기 검색·개발자 도구·클라이언트 변경을 완전히 차단할 수 없습니다. 이미 전달된 문항을 원격으로 회수할 수도 없습니다. 탭 이탈 기록은 다른 정상 동작으로도 발생할 수 있으며 부정행위 확정 근거가 아닙니다. 엄격한 기기 통제가 필요하면 별도 관리 기기와 전용 시험 브라우저가 필요합니다.

## 검증

`python3 test_server.py`는 임시 DB/서버에서 인증, 공개/잠금, 반별 분리, 문항 유출 경로, 저장/제출 검증과 재시작 후 데이터 유지를 확인합니다. 실제 학생에게 배포하기 전에 배포 주소의 HTTPS, 쿠키, 연결과 관리자 비밀번호를 확인하세요.

## 채점과 관리자 비밀번호

테스트 패키지의 실행기는 별도 비밀번호 입력 없이 시작합니다. 요청한 관리자 비밀번호의 소금값과 검증 해시만 `admin_auth.json`에 저장했고 학생에게는 제공하지 않습니다. 비밀번호 변경은 서버의 `ADMIN_PASSWORD` 설정으로 덮어쓸 수 있습니다.

16번은 정부(국가)·시민단체(시민) 차원의 답안을 분리해 저장합니다. 두 칸을 모두 작성하면 기본 3점, 한쪽에서 핵심 표현이 확인되면 4점, 양쪽에서 확인되면 5점을 제안합니다. 비어 있거나 한쪽만 작성된 기존 답안에는 0~2점을 제안합니다. 이전 버전의 통합 서술형 답안도 보존되며 교사 확인이 필요합니다. 핵심 표현 규칙은 의미·문맥·부정 표현을 완전히 이해하지 못하므로 최종 판단은 교사가 합니다. 관리자에서 학생별 객관식 정오, 자동 제안 이유, 서술형 최종 점수, 20점 만점 총점을 확인합니다. 서술형 점수는 0~5점 정수로 수정·저장하고 메모를 남기거나 자동 제안으로 되돌릴 수 있습니다. 수정 점수는 재시작 후에도 유지됩니다.

## 외부 공개

[Render에서 배포 설정 열기](https://render.com/deploy?repo=https://github.com/fung123-ksjeil/quiz2026)

1. Render에 로그인하고 GitHub 저장소 접근을 연결합니다.
2. Blueprint의 서비스와 현재 요금을 확인합니다. `render.yaml`은 SQLite 답안을 영구 보존하기 위해 Starter 서비스와 1GB 영구 디스크를 사용하므로 비용이 발생할 수 있습니다. 아직 서비스를 생성하거나 결제하지 않았습니다.
3. `ADMIN_PASSWORD`에 대화에서 지정한 관리자 비밀번호를 안전하게 입력합니다. GitHub에는 비밀번호나 검증 해시를 올리지 않습니다.
4. 배포가 완료되면 Render가 표시하는 HTTPS 주소를 사용합니다. 학생은 `/`, 관리자는 `/admin`, 연습문제는 `/practice`입니다.
5. 실제 배포 주소에서 반 만들기 → 공개 → 학생 입장 → 저장/제출 → 잠금 → 교사 점수 수정이 유지되는지 확인합니다. 운영 중인 답안을 보존하려면 영구 디스크를 유지하고 별도로 백업하세요.

GitHub Pages와 `python -m http.server`는 서버 API·관리자 인증·답안 저장을 제공하지 않습니다. 정적 사이트로 저장소 전체를 공개하지 마세요. 현재 클라우드 테스트 데이터는 Git에 포함되지 않습니다.
